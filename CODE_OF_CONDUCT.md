# Code of Conduct

This project follows the [Contributor Covenant, version 2.1][covenant],
which is the authoritative text if a question ever turns on the detail.
The short version:

- Be respectful. Assume competence and good faith in others.
- Criticize code and reasoning, not people.
- Harassment, personal attacks, and publishing others' private
  information are not tolerated, in the issue tracker or anywhere else
  someone is representing this project.

Report anything that needs attention to the maintainer,
[@hugof38](https://github.com/hugof38), by GitHub direct message or a
[private advisory](https://github.com/hugof38/fasti/security/advisories/new)
on this repository. Reports are handled confidentially. The maintainer
may edit or remove contributions and, where warranted, block accounts.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
